
# OrgMind AI

AI-Powered Organization Management and Intelligence System.

## Overview

OrgMind AI is an intelligent assistant that allows managers to retrieve organizational information through natural-language conversations.

## Planned Features

- Employee intelligence
- Attendance tracking
- Project management
- AI-powered database queries
- RAG-based document intelligence
- Manager dashboard

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- LangChain
- React

Backend foundation completed.
